# Prompt 03 — สร้างไฟล์พิมพ์ QR Label

ใช้เมื่อต้องการพิมพ์ label ติดชิ้นงาน Lamp / กล่องพาร์ท / จุดจัดเก็บ

---

เขียนสคริปต์ Python `tools/make_labels.py` ใน repo นี้:

**Input:** ไฟล์ CSV (คอลัมน์: regis_no, part_name, link) หรืออ่านตรงจาก Google Sheets export
**Output:** PDF พร้อมพิมพ์ ขนาด label 50×25 มม. (เลือก layout ได้: กระดาษ A4 ตัด หรือม้วน label ต่อเนื่อง)

แต่ละ label ประกอบด้วย:
- QR code (สร้างจากคอลัมน์ link) ด้านซ้าย ขนาด ~20×20 มม.
- ด้านขวา: regis_no ตัวหนา + part_name + บรรทัดเล็ก "สแกนเพื่อดูสถานะ/ที่เก็บ"

ข้อกำหนด: ใช้ lib `qrcode` + `reportlab`, ฟอนต์ไทยฝังใน PDF (โหลด Sarabun จาก Google Fonts ได้), มี margin กันตัดขอบ 2 มม., ทำ CSV ตัวอย่าง 3 แถวไว้ทดสอบ และเขียนวิธีใช้ท้ายไฟล์ script

---

## เกร็ดการใช้งานจริง
- พิมพ์ 2 ใบต่องาน: ติดชิ้นงาน 1 + ติดกล่อง/ถุง 1 | ตอนปิดงานติดที่จุดจัดเก็บอีก 1
- ใช้กระดาษ label กันน้ำ/ทนความร้อนถ้าชิ้นงานเข้า chamber
