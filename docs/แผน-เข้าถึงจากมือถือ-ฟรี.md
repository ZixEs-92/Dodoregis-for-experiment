# ทางเลือกให้เข้าถึง Dodoregis จากมือถือ (monitor / input) แบบฟรี

> อัปเดต 2026-07-14 · แนวคิด: แอปรันบนเครื่อง/เซิร์ฟเวอร์ในออฟฟิศ (SQLite อยู่ในองค์กร) แล้ว "เปิดทาง" ให้มือถือเข้าถึง — ไม่ต้องเช่า cloud

## บริบท
- แอปนี้ **ยังไม่มีระบบล็อกอิน** → ถ้าเปิดเป็น URL สาธารณะต้องมี "กำแพงล็อกอิน" กั้น หรือใช้เครือข่ายส่วนตัว
- หัวใจคือ **QR ติดชิ้นงาน** — สแกนแล้วต้องเปิดหน้างานได้ → ทางเลือกที่ให้ "เปิด URL ได้เลยจากเบราว์เซอร์มือถือ" เหมาะกับ workflow นี้สุด
- ก่อนใช้จริงควรรันแบบ production: `npm run build && npm run start` (เสถียรกว่า `npm run dev`) และตั้งให้เปิดอัตโนมัติเมื่อเปิดเครื่อง

## ตารางเทียบ (ทุกตัวฟรี)

| ตัวเลือก | ค่าใช้จ่าย | เข้าจากนอกออฟฟิศ | สแกน QR โดยใครก็ได้ | ต้องลงแอปบนมือถือ | ความปลอดภัย | ตั้งค่ายาก |
|---|---|---|---|---|---|---|
| **LAN (Wi-Fi ออฟฟิศ)** | ฟรีจริง | ❌ (เฉพาะใน Wi-Fi เดียวกัน) | ✅ (ในออฟฟิศ) | ไม่ต้อง | สูง (ไม่ออกเน็ต) | ง่ายสุด |
| **Tailscale** | ฟรี (6 users, อุปกรณ์ไม่จำกัด) | ✅ | ❌ (เครื่องที่สแกนต้องอยู่ใน tailnet) | ต้อง (Tailscale app) | สูงสุด (private mesh) | ปานกลาง |
| **Cloudflare Tunnel + Access** | ฟรี (tunnel unmetered · login wall ฟรี ≤50 คน) · *ต้องมีโดเมน ~100-300 บ./ปี* | ✅ | ✅ (เปิด URL ได้เลย มีหน้า login กั้น) | ไม่ต้อง | สูง (login OTP + WAF) | ปานกลาง |
| **Cloudflare Quick Tunnel** (`trycloudflare.com`) | ฟรีจริง 100% | ✅ | ✅ | ไม่ต้อง | ⚠️ ต่ำ (ไม่มี login, URL เปลี่ยนทุกครั้ง) | ง่าย |
| **ngrok (free)** | ฟรี (1 tunnel, 1 static domain) | ✅ | ✅ | ไม่ต้อง | ⚠️ ต่ำ-กลาง | ง่าย |

## รายละเอียดแต่ละตัว

### 1. LAN — ฟรีจริง เหมาะกับงานในออฟฟิศ ⭐ (สำหรับ lab)
เครื่องที่รันแอปเปิดค้างไว้ มือถือใน Wi-Fi เดียวกันเปิด `http://<LAN-IP>:3000`
- ตั้ง `APP_BASE_URL=http://192.168.x.x:3000` ก่อนพิมพ์ QR (มีอยู่แล้วในโปรเจค)
- **ข้อดี:** ฟรี เร็ว ข้อมูลไม่ออกนอกองค์กร สแกน QR ในแล็บได้ทันที
- **ข้อจำกัด:** ใช้ได้เฉพาะตอนอยู่ในออฟฟิศ · IP เครื่องอาจเปลี่ยน (ตั้ง static IP / DHCP reservation กันไว้)

### 2. Tailscale — ฟรี ปลอดภัยสุด สำหรับทีมประจำ
สร้างเครือข่ายส่วนตัว (mesh VPN) ลง Tailscale บนเครื่องเซิร์ฟเวอร์ + มือถือทุกเครื่อง → มือถือเข้าแอปผ่านชื่อ/IP ของเครื่องใน tailnet ได้จากทุกที่
- **ฟรี:** Personal plan สูงสุด **6 users**, อุปกรณ์ผู้ใช้ไม่จำกัด (ตั้งแต่ เม.ย. 2026)
- **ข้อดี:** ไม่เปิดสู่สาธารณะเลย ปลอดภัยสูงสุด ไม่ต้องมีโดเมน ชดเชยเรื่องแอปไม่มี auth ได้ดี
- **ข้อจำกัด:** ทุกมือถือต้องลง Tailscale + ล็อกอิน · **สแกน QR โดยคนนอก tailnet ไม่ได้** (เหมาะกับทีมประจำ ไม่เหมาะให้คนทั่วไปสแกน)
- ตั้ง `APP_BASE_URL` เป็นชื่อ MagicDNS ของเครื่อง (เช่น `http://lab-pc.tailXXXX.ts.net:3000`)

### 3. Cloudflare Tunnel + Access — เปิด URL จากที่ไหนก็ได้ + มีหน้า login ⭐ (ถ้าต้องเข้าจากนอก)
ลง `cloudflared` บนเครื่อง → สร้าง outbound tunnel เข้า Cloudflare (ไม่เปิดพอร์ต ไม่ต้องมี public IP) → ได้ URL `https://dodoregis.<โดเมนคุณ>` · เพิ่ม **Cloudflare Access** เป็นหน้า login (email OTP / Google) กั้นหน้า
- **ฟรี:** tunnel unmetered ไม่จำกัด · Access ฟรีถึง **50 users**
- **ข้อดี:** มือถือเปิด URL ได้เลยไม่ต้องลงแอป → **สแกน QR ได้จริง** · มี login wall + WAF ของ Cloudflare
- **ข้อจำกัด:** ต้องมี **โดเมน** (ผูกกับ Cloudflare ฟรี แต่ตัวโดเมน ~100-300 บาท/ปี — ไม่ฟรี 100%) · ตั้งค่าซับซ้อนกว่าเล็กน้อย

### 4. Cloudflare Quick Tunnel / ngrok — ฟรีจริงแต่ชั่วคราว
`cloudflared tunnel --url http://localhost:3000` ได้ URL `trycloudflare.com` ทันที (ไม่ต้องมีโดเมน) · ngrok ฟรีได้ 1 static domain
- **ข้อดี:** ฟรี 100% ตั้งง่าย เหมาะโชว์/ทดลอง
- **ข้อจำกัด:** ⚠️ **ไม่มี login กั้น** — ใครมี URL ก็แก้ข้อมูลได้ · Quick Tunnel URL เปลี่ยนทุกครั้งที่รัน (QR ที่พิมพ์ไปแล้วจะพัง) → **ไม่เหมาะใช้จริง** ใช้เดโมชั่วคราวเท่านั้น

## คำแนะนำตาม use case

- **ใช้ในแล็บ/ออฟฟิศเป็นหลัก (สแกน QR หน้างาน, กรอกข้อมูลบนพื้นที่):** → **LAN** พอแล้ว ฟรีจริง เร็วสุด
- **ทีมประจำ 1–10 คน ต้องเช็ค/กรอกจากนอกออฟฟิศด้วย:** → **Tailscale** (ฟรี ปลอดภัย) ลงแอปครั้งเดียวจบ
- **อยากให้ใครก็สแกน QR เปิดดูได้จากมือถือทุกที่ (ไม่ต้องลงแอป):** → **Cloudflare Tunnel + Access** (มีค่าโดเมนนิดหน่อย/ปี แต่คุ้ม)
- **แค่โชว์/ทดลองชั่วคราว:** → **Cloudflare Quick Tunnel** (แต่ห้ามใส่ข้อมูลจริง เพราะไม่มี login)

> เสริม: ไม่ว่าเลือกตัวไหน ถ้าจะเปิดออกสาธารณะ (ตัวเลือก 3-4) **ควรรีบทำระบบ auth ในแอป** (อยู่ใน backlog อยู่แล้ว) เป็นชั้นกันอีกชั้น
